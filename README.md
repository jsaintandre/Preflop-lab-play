# Preflop Lab

Play it at https://jsaintandre.github.io/Preflop-lab-play/

On an iPhone, open that link in Safari, tap Share, then Add to Home Screen, and always open Preflop Lab from that icon.

This repository only holds the built website. The source is in the private `preflop-lab` repository: run `npm run pages` there and copy everything in `pages/` (including `.nojekyll`) here.
